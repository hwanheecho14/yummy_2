# 🍚 밥약 (yummy)

한양대학교 ERICA 학생을 위한 **밥약·밥친구 매칭 웹사이트**입니다.
후배는 선배에게 부담 없이 밥약을 신청하고, 학년과 상관없이 공강이 맞는 밥친구도 찾을 수 있어요.
시간표로 겹치는 공강을 찾아 일시를 추천하고, 수락되면 연락처가 공개됩니다.

백엔드 없이 **프론트엔드만으로 동작**합니다. 모든 데이터는 브라우저의 `localStorage`에 저장되고,
처음 열면 데모용 예시 데이터가 채워집니다.

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

GitHub Pages로 배포하려면 저장소 **Settings → Pages**에서 `main` 브랜치의 루트(`/`)를 선택하세요.

## 데모 계정

로그인 화면의 **데모 계정으로 둘러보기** 버튼으로 비밀번호 없이 들어갈 수 있습니다.

| 버튼 | 계정 | 해볼 수 있는 것 |
| --- | --- | --- |
| 후배로 체험 | 박정환 (지능형시스템공학과 26학번 새내기) | 같은 학과 선배 김현성 확인, 겹치는 공강 추천, 밥약 신청, 밥친구 모집 참여 |
| 선배로 체험 | 김민준 (컴퓨터학부 23학번) | 받은 신청 수락·거절, 대화, 엔빵 계산, 시간표·프로필 수정 |

한 브라우저에서 계정을 바꿔 가며 **후배로 신청 → 선배로 로그인해 수락 → 후배로 연락처 확인** 흐름을 시연할 수 있습니다.
데이터를 처음 상태로 돌리려면 **내 프로필 → 데모 데이터 초기화**를 누르세요.

## 기능

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 회원가입·로그인 | 아이디/비밀번호 가입(비밀번호는 SHA-256 해시로 저장), 학과(ERICA 2026학년도 10개 단과대)·학번·출생연도 입력, 데모 계정 |
| F2 | 밥약 프로필 | 자기소개, 요일별 가능 시간 구간, 공개 전환. 종류는 선배(밥약 받기) 또는 밥친구 |
| F3 | 선배·밥친구 목록 | 선배 찾기 / 밥친구 찾기 탭, 우리 학과·단과대 강조, 나와 잘 맞는 순 정렬, 필터·검색, 학년·나이 표시 |
| F4 | 밥약 신청 | 월·일을 눌러 고르면 그날 가능한 2시간 시간대만 나옴, 후보 최대 3개 + 한마디 |
| F5 | 수락·거절 | 확정할 일시를 골라 수락, 7일 동안 응답이 없으면 자동 만료 |
| F6 | 연락처 공개 | 수락된 밥약에서만 서로의 연락처가 보임 |
| F7 | 내 밥약 | 받은/보낸 신청과 상태(대기·수락·거절·만료·취소), 대기 중인 신청 취소 |
| F8 | 알림 | 신청·수락·거절·만료·메시지·모집 알림과 안 읽은 개수 배지 |
| F9 | 신고·차단 | 신고 사유 접수, 차단하면 서로 목록에서 숨김 |
| F10 | 사이트 내 대화 | 신청마다 메시지를 주고받음, Enter로 보내기 |
| F11 | 시간표 올리기 | 주간 시간표에 수업 칸을 칠하면 공강 시간을 계산해 가능 시간에 채움, 시간표 이미지 첨부 |
| F12 | 겹치는 공강 추천 | 내 시간표와 상대 가능 시간이 겹치는 구간 표시, 추천 일시 3개 자동 채우기 |
| F13 | 좋아하는 메뉴·맛집·알레르기 | 프로필에 메뉴·추천 맛집·알레르기, 신청·대화 화면에 알레르기 안내 |
| F14 | 밥친구 모집·그룹 밥약 | 번개 모집(2~6명)과 2:2·3:3 그룹 밥약, 참여하면 멤버 연락처 공개 |
| F15 | 엔빵 계산기 | 총 금액 ÷ 인원을 10원 단위로 올려 계산, 송금처 메모와 함께 대화방에 공유 (실제 송금 없음) |
| F16 | 학식·맛집 | 교내 식당 요일별 메뉴(예시), 학교 주변 맛집·카페를 지도 앱에서 바로 검색, 추천 맛집 모아보기 |
| 이벤트 | 수요일 공강 커피 이벤트 | 매주 수요일 13:00~15:00(전체 공강)로 밥약이 확정되면 두 사람 모두 커피 기프티콘 추첨에 응모 |
| 기타 | 테마 | 라이트/다크 모드 전환 (기기 설정 따르기 포함) |

## 기획안 대비 구현 현황

| 기획안 항목 | 구현 |
| --- | --- |
| 선배 프로필 등록 (전공, 학번, 자기소개, 가능 요일·시간) | F2, F11 |
| 매칭 및 신청 | F3, F4 |
| 승인 및 연락 (수락 시 연락처 공개 또는 자체 채팅) | F5, F6, F10 |

| 맞춤형 선호 메뉴 프로필 (음식, 알레르기) | F13 |
| 교내 학식 정보 | F16 (예시 메뉴, 실제 식단 연동은 백엔드 필요) |
| 일반 밥친구 매칭 | F3 밥친구 탭, F14 |
| 그룹 밥약 (2:2 등) | F14 |
| 더치페이(엔빵) 정산 | F15 |

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   스타일 (모바일 우선, 라이트/다크 테마)
js/theme.js     테마 전환 (페이지가 그려지기 전에 적용)
js/store.js     데이터 저장소 (localStorage, 예시 데이터, 신청·모집·공강 계산 규칙)
js/app.js       화면 렌더링, 해시 라우팅, 이벤트 처리
```

## 협업 규칙

- `main`에 직접 push하지 않고, 기능마다 브랜치를 만들어 PR로 merge합니다.
- 브랜치 이름: `feature/…`(기능), `fix/…`(버그·데이터 수정), `design/…`(디자인), `docs/…`(문서), `refactor/…`
- 커밋 메시지: `feat:`, `fix:`, `style:`, `refactor:`, `docs:` 접두어 + 무엇을 왜 바꿨는지 한글로

## 한계

- 데이터가 각자의 브라우저에만 저장되므로, 서로 다른 기기의 사용자끼리는 실제로 신청을 주고받을 수 없습니다.
  실서비스로 키울 때는 Firebase나 Supabase 같은 백엔드를 붙여야 합니다.
- 학식 메뉴는 예시이고, 예시 프로필의 사람·가게 이름은 지어낸 이름입니다.
