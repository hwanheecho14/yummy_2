# 🍚 밥약 (yummy)

대학교 후배가 선배에게 부담 없이 **밥약**을 신청하고, 선배가 수락하면 연락처가 공개되는 선후배 매칭 웹사이트입니다.

백엔드 없이 **프론트엔드만으로 동작**합니다. 모든 데이터는 브라우저의 `localStorage`에 저장되며, 처음 열면 데모용 더미 데이터가 채워집니다.

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

GitHub Pages로 배포하려면 저장소 **Settings → Pages**에서 `main` 브랜치의 루트(`/`)를 선택하세요.

## 데모 계정

로그인 화면의 **데모 계정으로 둘러보기** 버튼으로 비밀번호 없이 들어갈 수 있습니다.

| 버튼 | 계정 | 해볼 수 있는 것 |
| --- | --- | --- |
| 후배로 체험 | 박정환 (지능형시스템공학과 26학번 새내기) | 선배 찾기, 밥약 신청, 수락된 밥약의 연락처 확인 |
| 선배로 체험 | 김민준 (컴퓨터학부 20학번) | 받은 신청 수락·거절, 선배 프로필 수정 |

한 브라우저에서 계정을 바꿔 가며 **후배로 신청 → 선배로 로그인해 수락 → 후배로 연락처 확인** 흐름을 시연할 수 있습니다.
데이터를 처음 상태로 돌리려면 **내 프로필 → 데모 데이터 초기화**를 누르세요.

## 기능

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 회원가입·로그인 | 아이디/비밀번호 가입(비밀번호는 SHA-256 해시로 저장), 데모 계정 로그인 |
| F2 | 밥약 프로필 | 자기소개(300자), 요일별 가능 시간 구간, 공개/비공개 전환. 종류는 선배(밥약 받기) 또는 밥친구 |
| F3 | 선배·밥친구 목록 | 선배 찾기 / 밥친구 찾기 탭, 우리 학과·단과대 강조, 학과·요일·시간대 필터, 이름·메뉴 검색 |
| F4 | 밥약 신청 | 월·일을 눌러 고르면 그날 가능한 2시간 시간대(1시간 간격)만 나옴, 최대 3개 + 한마디(200자). 같은 상대에게 진행 중인 신청은 1건 |
| F5 | 수락·거절 | 확정할 일시를 골라 수락, 7일 동안 응답이 없으면 자동 만료 |
| F6 | 연락처 공개 | 수락된 밥약에서만 서로의 연락처가 보임 |
| F7 | 내 밥약 | 받은/보낸 신청과 상태(대기·수락·거절·만료·취소), 대기 중인 신청 취소 |
| F8 | 알림 | 신청 도착, 수락·거절, 만료 알림과 안 읽은 개수 배지 |
| F9 | 신고·차단 | 신고 사유 접수, 차단하면 서로 목록에서 숨김 |
| F10 | 사이트 내 대화 | 대기 중이거나 수락된 신청마다 후배와 선배가 메시지를 주고받음, 새 메시지 알림 |
| F11 | 시간표 올리기 | 주간 시간표에 수업 칸을 칠하면 공강 시간을 계산해 가능 시간에 채움, 시간표 이미지 첨부 |
| F12 | 좋아하는 메뉴·맛집 | 프로필에 좋아하는 메뉴(5개)와 추천 맛집(3곳), 카드와 상세에 표시 |
| 이벤트 | 수요일 공강 커피 이벤트 | 매주 수요일 13:00~15:00(전체 공강)로 밥약이 확정되면 두 사람 모두 커피 기프티콘 추첨에 응모 |

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   스타일 (모바일 우선, 다크 모드 지원)
js/store.js     데이터 저장소 (localStorage, 더미 데이터, 신청 규칙)
js/app.js       화면 렌더링, 해시 라우팅, 이벤트 처리
```

## 한계

데이터가 각자의 브라우저에만 저장되므로, 서로 다른 기기의 사용자끼리는 실제로 신청을 주고받을 수 없습니다.
실서비스로 키울 때는 Firebase나 Supabase 같은 백엔드를 붙여야 합니다.
